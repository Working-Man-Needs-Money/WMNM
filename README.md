
# WM|NM (Working Man Needs Money)
- https://working-man-needs-money.github.io/WMNM/

Welcome to **Working Man Needs Money (WM|NM)** – a collaborative platform designed to connect freelancers, developers, and entrepreneurs.

Our goal is to provide a supportive network where everyone's skills can be leveraged to create high-quality solutions.

## How to Run the Project Locally in VS Code

1. **Check if Jekyll is installed**:
   ```bash
   jekyll -v
   ```

2. **Install Jekyll if not installed**:
   ```bash
   sudo apt update
   sudo apt install jekyll
   ```

3. **Verify the installation**:
   ```bash
   jekyll -v
   ```

4. **Navigate to the WMNM directory and run the server**:
   ```bash
   jekyll serve
   ```
   The site will be available if done correctly
